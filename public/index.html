Location captured automatically from this device.
iPhone / Safari
  1. Tap the Page Menu in Safari.
  2. Open Website Settings.
  3. Set Location to Allow.
  4. If still blocked: iPhone Settings → Privacy & Security → Location Services → Safari Websites → While Using the App, and turn Precise Location ON.
  5. Return here and tap Retry Location.
Android / Chrome
  1. Open this website in Chrome.
  2. Open Site settings for this website.
  3. Set Location permission to Allow.
  4. Make sure phone Location / GPS is turned on.
  5. Return here and tap Retry Location.
